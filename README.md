# Directory — รายชื่อผู้ให้บริการกองถ่ายภาพยนตร์

เว็บค้นหารายชื่อธุรกิจและผู้ให้บริการสำหรับงานกองถ่าย ข้อมูลมาจาก Google Form → Google Sheet โดยมีหน้าหมวดธุรกิจ หน้ารายการค้นหา/กรอง และหน้ารายละเอียดพร้อมช่องทางติดต่อ อ่านขอบเขตงาน ธีม และเรื่องที่ต้องยืนยันใน [`business.md`](./business.md)

> สถานะปัจจุบัน: เดโม่ 3 หน้า เชื่อม Google Apps Script ของชีตตัวอย่างแล้ว ใช้ภาพ key art ใน `public/` **เดโม่นี้แสดงแถวที่ `published=FALSE` ตามที่เจ้าของงานอนุญาตให้ดูชั่วคราวเท่านั้น ห้ามเปิดลิงก์เดโม่เป็นสาธารณะ** ก่อนเปิดจริงต้องกำหนดรายการที่เผยแพร่ได้และเปิดใช้ตัวกรอง `published=TRUE` ที่ฝั่งเซิร์ฟเวอร์

## เทคโนโลยี

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4
- pnpm (ดูเวอร์ชันใน `package.json`)

## รันในเครื่อง

ติดตั้ง Node.js เวอร์ชันที่รองรับ Next.js 16 (ขั้นต่ำ 20.9) และ pnpm แล้วรัน:

```bash
pnpm install
pnpm dev
```

เปิด http://localhost:3000

ตรวจสอบก่อนส่งงาน:

```bash
pnpm lint
pnpm build
```

## โครงสร้างเริ่มต้น

- `app/page.tsx` — หน้าแรก การ์ดหมวด และช่องค้นหา
- `app/providers/page.tsx` — รายการ ค้นหา/กรองหมวดและพื้นที่ผ่าน query string
- `app/providers/[id]/page.tsx` — รายละเอียดและช่องทางติดต่อ
- `lib/providers.ts` — ดึงข้อมูลจาก GAS บนเซิร์ฟเวอร์และเลือกฟิลด์ที่แสดงได้
- `app/globals.css` — สีธีมรวมใน `:root` และสไตล์ทุกหน้า
- `public/` — key art ที่ได้รับจากผู้ว่าจ้าง
- `business.md` — ขอบเขตงาน ข้อจำกัด และรายการที่ต้องยืนยัน

## ข้อมูลเดโม่และข้อจำกัดก่อนส่งจริง

- ใช้แท็บ `Directory` จาก endpoint Google Apps Script ใน `lib/providers.ts` เท่านั้น; ไม่ส่งข้อมูลดิบทั้งชีตไปยัง browser และดึงใหม่เมื่อ cache หมดอายุ 5 นาที
- การค้นหาจะทำฝั่งเซิร์ฟเวอร์จากข้อมูลที่แมปแล้ว; `published=FALSE` ยังแสดงในเดโม่ตามที่ผู้ว่าจ้างยอมให้ดูเฉพาะกลุ่ม **Next.js ไม่ได้ทำให้หน้าเว็บเป็นส่วนตัวอัตโนมัติ** หาก deploy ต้องตั้งระบบจำกัดสิทธิ์ (เช่น deployment protection) ก่อนแชร์กับผู้ว่าจ้าง
- หน้าเดโม่ใช้กราฟิกธีมแทนรูปผู้ให้บริการ เนื่องจาก `portfolio_link` บางแถวเป็นลิงก์โซเชียล/โฟลเดอร์หรือข้อความ ไม่ใช่ไฟล์รูปที่ฝังได้โดยตรง
- ก่อนเปิดจริง: ยืนยันคอลัมน์และแถวที่เปิดเผยได้, ใช้ `published=TRUE`, จำกัดสิทธิ์ endpoint GAS, ย้าย URL/ข้อมูลรับรองไปตั้งค่าฝั่งเซิร์ฟเวอร์ของบัญชีผู้ว่าจ้าง, และตรวจสิทธิ์การแสดงรูปจาก Drive
- อัปเดตชีตแล้วรอไม่เกินประมาณ 5 นาทีเพื่อให้ข้อมูลเดโม่เปลี่ยนตาม; เมื่อส่งจริงให้จัดทำคู่มือการกรอกและเผยแพร่ข้อมูลตาม workflow ที่ผู้ว่าจ้างกำหนด
